ARLAMX v2.7.5

A C++ spacecraft plant and a Python trainer for very-low and low Earth orbit. Open the user guide for commands and the three ways to run it. Open the physics reference for the equations.

User guide

How to build, which command runs which study, free-molecular flow for a spacecraft, the onboard control loop, deep-RL training, STL simplification, and the Python libraries. Dark theme, no network needed.

Physics reference

Sentman and Walker–CLL aerodynamics, radiation pressure, gravity, atmosphere, attitude laws, the Gym environment, configuration, and validation notes.

Commands

python main.py is the front door: train, decay, sweep, quantize, and the simulation tools.
